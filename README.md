# delta⁹ — ППУ / моніторинг повітряних загроз

Статичний застосунок. Бекенда немає.

## Запуск локально

Потрібен http(s), `file://` не підійде (сервіс-воркер і fetch).

    npx serve .          # або будь-який статичний сервер
    python3 -m http.server

## Деплой на GitHub Pages

1. Завантаж **вміст** цієї теки в корінь репозиторію (щоб `index.html` лежав у корені, а не в підтеці).
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `root`.
3. Файл `.nojekyll` уже є — Jekyll не чіпатиме теки й файли.

## Загрози в повітряному просторі (ППУ)

Три джерела, зведені в один список цілей:

| Джерело | Що дає | Доступ |
|---|---|---|
| **mapa.ua** `/api/v1` | цілі, атаки, архів, реплей | відкрите, кожні 10 с |
| **NEPTUN** `neptun.in.ua/api/v1` | цілі + офіційні тривоги (області й райони) | відкрите, кожні 6 с |
| **Київ Цифровий** airAlertState | статус і причина тривоги в м. Києві | через `kyiv-proxy.worker.js` |

Тумблери й лічильники джерел — «Загрози» → «Ефір» → «Джерела даних»;
зведена картина й офіційні тривоги — панель **«Купол»**.

**Зведення (щоб цілі не множилися).** Записи різних джерел вважаються однією
ціллю, якщо збігається клас (дрон / крилата / балістика / КАБ) і відстань ≤ 20 км
— причому позиції спершу зводяться численням шляху на один момент часу, бо
джерела фіксують ту саму ціль у різні секунди. Зливаються лише свіжі записи:
mapa.ua тримає `active` годинами після останньої фіксації, і зливати такий хвіст
зі свіжою ціллю з іншого джерела означало б вигадати позицію. Геометрія (точка,
курс, швидкість) береться з найсвіжішого джерела, кількість у групі — максимум,
а не сума; `id` лишається від джерела з вищим пріоритетом (mapa.ua), щоб трек
не перестрибував.
Запис NEPTUN з `areaOnly: true` (названо лише область, точки немає) НЕ стає
ціллю — він підсвічує область, як і належить.

NEPTUN вимагає видимого посилання на джерело — воно є в панелі «Купол» і в
«Джерелах даних».

Панель «Загрози»:

| Вкладка | Що показує |
|---|---|
| Ефір | лічильник, «загрози поряд», фільтри типів і станів, параметри шару, список цілей |
| Курси | власний супровід цілей: два кліки / клік+курс, числення шляху, слід, ETA до підрозділів, тривога наближення (звук+пуш), стрічка Telegram-каналів |
| Групи | зони пуску та заявлені міста-цілі |
| Хроніка | зведення атаки + все, що зʼявилось за 10 хвилин |
| Реплей | календар, атаки за добу, таймлайн-скрабер |
| Тривоги | підключення проксі alerts.in.ua |

**Поріг свіжості.** mapa.ua тримає статус `active` довго після останньої фіксації,
тому ціль вважається такою, що реально в повітрі, лише в межах вікна від `last_seen`:
балістика 8 хв, крилата 15, КАБ 12, реактивний БпЛА 15, Shahed 25.
Старіші приховані (у шапці видно скільки). Тумблер «Тільки свіжі дані · реалтайм»
вимикає фільтр і показує повний зріз.

## Підрозділи (APP-6)

«Нове розміщення» → клік по мапі (або координати вручну) → покроковий візард
символу: приналежність → середовище → позначка → ампліфікатори → назва.
Далі картка підрозділу: позиція, символ, ресурси, роль у симуляції,
підпорядкування, звʼязки.

На мобільному (≤860 px) панель ховається на час вибору точки — знизу зʼявляється
плашка з підтвердженням / скасуванням, як в інструментах малювання.

## Повітряні тривоги по областях

alerts.in.ua не віддає CORS і вимагає токен, тому потрібен власний проксі:

1. Токен: `alerts.in.ua/api-request`.
2. Cloudflare → Workers & Pages → Create Worker → код з `alerts-proxy.worker.js`.
3. Settings → Variables and Secrets → Secret `ALERTS_TOKEN`.
4. Адресу воркера встав у «Загрози» → «Тривоги» → Проксі.

Воркер кешує відповідь на 15 с, щоб не впертись у ліміт 8–12 запитів/хв.

Без цього проксі тривоги все одно працюють: офіційні сигнали по областях і
районах приходять з NEPTUN (ключ не потрібен).

## Тривога в м. Києві (Київ Цифровий)

Портал даних Києва не віддає CORS-заголовки, тому `airAlertState` не читається
з браузера напряму:

1. Cloudflare → Workers & Pages → Create Worker → код з `kyiv-proxy.worker.js`.
2. Deploy (токен не потрібен — дані відкриті).
3. Адресу воркера встав у «Купол» → «Проксі · Київ Цифровий».

Джерело додає причину тривоги (`missile`, `massive-drone`, `drone`) — те, чого
немає в інших фідах. Поки проксі не підключено, джерело вимкнене й не шумить.

## Канали моніторингу (вкладка «Курси»)

Стрічка публічних Telegram-каналів без токенів — через власний проксі:

1. Cloudflare → Workers & Pages → Create Worker → код з `tg-proxy.worker.js`.
2. Адресу воркера встав у «Загрози» → «Курси» → «Канали моніторингу».
3. Додай канали (типово `kpszsu`, до 6). Повідомлення «з X → на Y»
   кнопкою «➤ ціль» стає ціллю з курсом; ETA до підрозділів рахується наживо.

## Модулі «Купол» і «FPV»

delta9 на старті сам запитує чотири дозволи: геопозицію, камеру й мікрофон одразу, компас — на
перший дотик (iOS вимагає жесту). Кнопки правої рейки відкривають **бокову панель налаштувань**
(щоразу): стан давачів із дотапуванням відсутніх, «Моя позиція», налаштування модуля, кнопка
**«Запуск»** унизу. Купол не відкривається без камери, геопозиції й компаса — при відмові
екран показує, як увімкнути дозвіл у системі. На пристрої без давачів (десктоп) — режим
«Купол без давачів»: купол за даними, позиція з геолокації або центру мапи. Налаштування
живуть у `localStorage` (`d9.mod.set`).

Обидва модулі вшиті в один документ: код кожного загорнутий у власну область видимости
(`window.Delta9KupolFactory(root, host)`, `window.Delta9FPVFactory(root, host)`), стилі
переписані під `#kupol-root` / `#fpv-root`, усі `document.querySelector` замкнені на корінь
модуля. Стартові екрани та назви оригіналів (ЖУЙКА, лобі МФ-3000, знак Ж⃝) прибрані.

| | Купол | FPV |
|---|---|---|
| Цілі | зведений потік delta9 (mapa.ua + NEPTUN), власне опитування вимкнене | режим «Реальні цілі з мапи»: лічильник і напрямок у HUD, дрони ближче 1.4 км з'являються в сцені |
| Позиція | `watchPosition` delta9 → `api.setMe` | точка старту `loadMap(lat, lon)` |
| Тривоги | області з delta9 → підсвітка й «хвиля тривоги» | — |
| Прибрано | демо, сторінка МАПА, архів атак, тріангуляція, стрічка | старт-екран, лобі, повний екран |
| Закрити | кнопка «Закрити» внизу — зупиняє давачі, голос, 3D і повертає на мапу | кнопка «✕ Закрити» угорі — зупиняє симуляцію й повертає на мапу |

Локація користувача в самому delta9: маркер «Я» і коло радіусу даних (50–250 км, з
налаштувань Купола), мапа центрується на тобі при відкритті модуля.

Синхрон із мапою (перевірено): геопозиція → `_me` → шари «Я» на мапі → `api.setMe` у Куполі
(`S.me`, магнітне схилення, домашня точка тривог) → точка старту FPV. Цілі: кожне зведення
delta9 (`mpCompose`) → `setTargets` в обидва модулі; у Куполі delta9 — єдине зареєстроване
джерело (`SRC.items.d9`, `srcTick` вимкнено), тому власний цикл фіду нічого не стирає; FPV
отримує лише свіжі цілі — ті самі, що бачить мапа. Області під тривогою → `api.setAlerts`.

Польова діагностика в консолі: `__d9` — екземпляр застосунку (`__d9.state.mod`,
`__d9._me`, `__d9._kupolApi`, `__d9._fpvApi`).

Джерела збірки модулів: `uploads/zhuika/src/*` і `uploads/…/index.html` (myFPV) у проєкті дизайну;
перезбірка — скрипт-трансформація, а не ручні правки в `js/kupol.js` / `js/fpv.js`.

## Зовнішні залежності (CDN, потрібен інтернет)

MapLibre GL, satellite.js, PIXI, mapa.ua API, NEPTUN API, тайли ArcGIS/CARTO,
Open-Meteo, geoBoundaries, DeepState; для FPV — three.js r128 і nipplejs (cdnjs), OSM/Overpass,
рельєф AWS Terrarium, шрифти Google Fonts.

## Відмова від відповідальності

NEPTUN і mapa.ua — інформаційні агрегатори, а не офіційні системи оповіщення.
Дані наближені й мають довідковий характер. Не використовуй для рішень
щодо безпеки — орієнтуйся на офіційні канали оповіщення.
